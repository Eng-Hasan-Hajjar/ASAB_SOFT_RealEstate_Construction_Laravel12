# ما الجديد في V3
- ترحيل إضافي للمالية والمخزون النقدي/البنكي والحجوزات وسجلات مراجعة Excel.
- محرك مالي للحركات اليدوية والمدفوعات والفواتير والتحويلات الداخلية.
- تقرير يومي وشهري حسب العقار مع أرصدة الفواتير ونسبة الإشغال.
- مولد فواتير الإيجارات الشهرية مع منع الازدواج.
- شاشة حجوزات ومواعيد التسكين، وفحص التعارضات.
- معاينة XLSX أو CSV داخل منطقة مراجعة مشفرة.
- وثائق تشغيل وتحديث وتقييم قبول يدوي.

توافق ترقية V2: الإبقاء على الجداول الأصلية؛ استخدم `php artisan migrate` ولا تستخدم `migrate:fresh`.
