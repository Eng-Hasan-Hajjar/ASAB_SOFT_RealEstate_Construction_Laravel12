# عصب سوفت — تجهيز الحسابات واستيراد ملفات العقارات Excel

**الإصدار:** إضافات متوافقة مع مشروع ASAB SOFT Real Estate / Finance V3 — Laravel 12 / MySQL.

## تنبيه مهم للغاية

- **هذه الحزمة تتضمن شيفرة فقط.** بيانات العميل الحساسة تأتي في ZIP منفصل باسم `ASAB_SOFT_Excel_Private_Seed_Data.zip`، **لا ترفع هذا الملف أو ملفاته إلى GitHub أو أي مستودع عام، ولا ترسله إلى جهات غير مخولة**.
- قبل أي شيء: احتفظ بنسخة احتياطية من قاعدة `asab_realty` ومجلد المشروع وملف `.env`؛ واستخدم قاعدة بيانات اختبار أولاً.
- **لا تنفّذ** `migrate:fresh` أو `db:wipe` أو `migrate:refresh` على قاعدة بها بيانات.
- لا تنسخ ملف `.env` من أي حزمة فوق ملفك الموجود، ولا تشارك كلمات المرور أو `APP_KEY`.
- لن يقوم هذا الاستيراد بإنشاء فواتير أو قيود محاسبية أو مدفوعات؛ فملفات Excel تحتوي بيانات تاريخية وصيغاً غير متجانسة، وبعضها أخطاء حسابية. جميع الصفوف الأصلية تُحفظ للمراجعة.

## 1. فك الحزمتين

أوقف `php artisan serve` ثم فك **حزمة الكود** فوق **جذر مشروع V3**، وهو المجلد الذي يحتوي على `artisan` و`composer.json`؛ ولا تحذف `vendor`.

فك **حزمة البيانات الخاصة** فوق المجلد نفسه. يجب أن يصبح لديك:

```
project/
├── app/Console/Commands/AsabSetPassword.php
├── app/Console/Commands/AsabSeedAudit.php
├── database/seeders/AsabInitializeAccountsSeeder.php
├── database/seeders/AsabClientExcelSeeder.php
├── storage/app/asab-private-import/manifest.json
└── storage/app/asab-private-import/source_01.json.gz ... source_14.json.gz
```

لا حاجة لإعادة تنزيل Composer إذا كان مجلد `vendor` موجوداً ومتوافقاً مع الإصدار الحالي.

## 2. اضبط `.env` داخل الملف، وليس في CMD

في نافذة CMD داخل مجلد المشروع نفّذ:

```cmd
notepad .env
```

أضف في نهاية الملف **بقيم حقيقية خاصة بك وبكلمات مرور جديدة وقوية**:

```dotenv
# حساب مالك المنصة؛ مطلوب عندما لا يوجد super_admin مسبقاً.
PLATFORM_OWNER_NAME="مالك منصة عصب سوفت"
PLATFORM_OWNER_EMAIL="REPLACE_PLATFORM_OWNER_EMAIL"
PLATFORM_OWNER_PASSWORD="REPLACE_WITH_LONG_UNIQUE_PASSWORD_1"

# شركة العميل الأول: الاسم مؤقت حتى تزودنا باسمه التجاري الصحيح.
ASAB_CLIENT_COMPANY_SLUG="asab-pilot-client"
ASAB_CLIENT_COMPANY_NAME="إدارة عقارات العميل التجريبي"
ASAB_CLIENT_CITY="غير محدد"

# مدير شركة العميل؛ يجب أن يختلف بريده عن مالك المنصة.
ASAB_COMPANY_ADMIN_NAME="مدير شركة العميل"
ASAB_COMPANY_ADMIN_EMAIL="REPLACE_COMPANY_ADMIN_EMAIL"
ASAB_COMPANY_ADMIN_PASSWORD="REPLACE_WITH_LONG_UNIQUE_PASSWORD_2"

# بيانات المستأجرين المرشحة: فعّلها بعد مراجعة سياسة الخصوصية وصحة المصدر.
ASAB_IMPORT_CONTACTS=false
# إنشاء عقود تاريخية كمسودات فقط (اختياري بعد المراجعة)
ASAB_IMPORT_DRAFT_LEASES=false

DEMO_DATA=false
```

**لا تستخدم كلمات المرور المثال**. في ملف `.env` الحالي لديك `DEMO_COMPANY_PASSWORD=123456789`؛ هذه كلمة لا تحقق شرط 12 محرفاً ولن تنشئ حساباً بسبب `DEMO_DATA=false`. لا تعتمد عليها، ولا تستخدم `DEMO_COMPANY_*` لإعداد الحسابات الواردة هنا.

إذا كان حساب `super_admin` موجوداً سابقاً، فلا يلزم إعادة إنشائه؛ لن يغير السيدر كلمة مروره. إذا فقدت كلمة مروره، انظر قسم استعادة كلمة المرور.

## 3. إنشاء الحسابات والشركة

```cmd
php artisan optimize:clear
php artisan migrate
php artisan db:seed --class=AsabInitializeAccountsSeeder
```

ينشئ السيدر **حساب مالك المنصة** (إذا لم يكن موجوداً)، و**شركة العميل** وحساب **مدير الشركة**، وحسابين ماليين بصفر افتتاحي (صندوق وبنك). لا يعيد ضبط كلمات المرور الموجودة، ولا ينشئ بيانات تجريبية عشوائية. إذا كان البريد مستخدماً بدور أو شركة أخرى فسيوقف التنفيذ دون تغيير الدور تلقائياً.

### إذا ظهرت «بيانات الدخول غير صحيحة»

تأكد من أنك تستعمل أحد بريدي `PLATFORM_OWNER_EMAIL` أو `ASAB_COMPANY_ADMIN_EMAIL` مع كلمة المرور التي ضبطتها. إذا كان الحساب **موجوداً بالفعل** وتريد تغيير كلمة مروره محلياً، نفّذ:

```cmd
php artisan asab:account-password YOUR_EXISTING_EMAIL
```

سيطلب كلمة المرور الجديدة مرتين دون إظهارها على الشاشة. لا تكتب كلمة المرور في CMD ولا ترسلها إلى أي أحد.

- حساب مالك المنصة يذهب إلى `/platform` ثم يختار «فتح مساحة الشركة».
- حساب مدير الشركة يذهب مباشرة إلى `/dashboard`، ثم `/manage/properties` و`/manage/units` و`/imports`.

## 4. استيراد كل صفوف Excel إلى منطقة مراجعة مشفرة

بعد فك حزمة البيانات الخاصة:

```cmd
php artisan db:seed --class=AsabClientExcelSeeder
php artisan asab:seed-audit
php artisan serve
```

نتائج المصدر المعلنة بعد تحليل الملفات **بحسب أوراق Excel الأصلية**:

| البيانات | العدد |
|---|---:|
| ملفات Excel الأصلية | 14 |
| أوراق Excel | 398 |
| صفوف غير فارغة محفوظة للمراجعة | 18,647 |
| ملفات عقارات | 12 |
| أوراق يمكن التعرف عليها كوحدات | 391 |
| صفوف مرشحة لمعلومات مستأجرين | 1,765 |
| عقود مرشحة ذات تاريخين ميلاديين ومبلغ قابلين للفهم | 16 |
| صفوف بها أخطاء صيغ Excel صريحة | 5 |

الصفوف المرشحة ليست سجلات عقود مؤكدة؛ لا تُنشأ فاتورة، ولا يُسجل مبلغ محصل، ولا يُحسب رصيد صندوق أو بنك تلقائياً. يبقى كل صف في `/imports` للمراجعة. أول استيراد ينشئ **12 عقاراً** و**391 وحدة** مبدئياً (إذا كانت قاعدة الشركة فارغة)، وجميعها **غير منشورة وغير متاحة للبيع** إلى حين مراجعة حالتها. يتم إنشاء الوحدات وفق أسماء الأوراق الأصلية، من دون تخمين الأسعار الشهرية أو الإشغال.

### استيراد المستأجرين اختيارياً

لإنشاء سجلات اتصالات من الصفوف ذات الاسم المعرّف، عدّل `.env`:

```dotenv
ASAB_IMPORT_CONTACTS=true
```

ثم شغّل `php artisan optimize:clear` وأعد `php artisan db:seed --class=AsabClientExcelSeeder`. يحتفظ الاسم ورقم الهاتف كما وردا بالمصدر، **ولا يعني إدراج الاسم أن المستأجر الحالي للوحدة قد تأكد**.

### العقود التاريخية (حذر إضافي)

بعد مراجعة السجلات فقط، يمكن اختيار إنشاء مسودات عقود لما أمكن تفسير تاريخيه ومبلغه، بتفعيل:

```dotenv
ASAB_IMPORT_DRAFT_LEASES=true
```

يجب أن يكون `ASAB_IMPORT_CONTACTS=true`. تُستورد كـ **مسودة `draft`** وبفترة سداد `custom`، بلا تفعيل تلقائي ولا استحقاقات أو قبض. لا يتم تحويل التاريخ الهجري تلقائياً إلى ميلادي، ولا يُفترض أن مبلغ Excel هو إيجار شهري.

## 5. حماية البيانات والتحقق

- حزمة البيانات الحساسة (JSON.GZ) تحتوي معلومات أشخاص وهويات اتصال، وهي غير مشفرة داخل ZIP قبل الاستيراد؛ خزّنها في مكان خاص وآمن، ثم امنع وصول الموقع إليها. **بعد الاستيراد تُخزّن الصفوف ضمن `import_rows.payload` بتشفير Laravel** بواسطة `APP_KEY`.
- لا تنقل مجلد `storage/app/asab-private-import` إلى `public`، ولا ترفعه إلى GitHub. لا تدفع هذه الملفات إلى أي مزود سحابي دون موافقة العميل وضوابط نقل البيانات.
- `APP_KEY` الحالي لا يجب تغييره بعد استيراد الصفوف، وإلا قد تتعذر قراءة البيانات المشفرة؛ إذا تعرّض للتسريب بالفعل، خطّط لتدويره ونقل البيانات بالتدرج وليس بشكل عشوائي.
- افحص `/imports` و`/manage/properties` و`/manage/units`، ثم طابق عينة من العقد والفاتورة والسند مع دفتر Excel الأصلي قبل الاعتماد المالي.
- **الاستيراد قابل لإعادة التشغيل**: يتجنب تكرار دفعات المصدر ونفس أسماء العقارات ورموز الوحدات والسجلات نفسها. لا يحدّث يدوياً ما صححته لاحقاً داخل النظام.
- إذا استلمت نسخة Excel معدلة لاحقاً، ستظهر كدفعة مصدر مختلفة؛ يلزم إجراء تسوية قبل دمج التعديلات كي لا تنشأ تعارضات.

**التوصية:** شغّل الاستيراد أولاً على نسخة اختبار من `asab_realty`، ثم اعتمد العقارات والوحدات والمستأجرين والعقود تدريجياً.
